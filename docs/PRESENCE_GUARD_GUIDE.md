# 第五轮：未知结构不能变成已知结构

基于第四轮补丁。只修改context_guard.py、context_agent.py的拦截提示，新增8个测试方法及真实失败的最小回放fixture。

## 原因与范围
variants_01的浑水问题中，模型把未知结构写成“附近已知的植被”。新检查在结构unknown/unanswered/未观察到时，识别有限的“已知/已确认的结构”“现场/这里/附近/岸边有或存在结构”表述。保存原始回答、冲突原因，最终返回证据不足，不额外调用模型。

条件句与明确不确定表达有负例测试。此规则不是语义核查，仍可能漏拦或误拦；没有处理所有部分确认情形，也没有修复K005地域条件遗漏。知识卡与旧评分不变。

如出现结构追问选择0。然后/new输入“我在湖泊岸边，看到倒木，应该先观察哪里？”，最后/exit保存。

检查：未知结构不能被写成现场已知；明确倒木仍可列为观察候选。
如果answer_origin=context_guard_v1且有unobserved_to_present冲突，说明规则拦截了模型错误；不算模型回答正确。如果模型自然返回证据不足，只证明本次没有该错误，不能据此声称真实拦截已触发。
