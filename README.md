# LureSense Starter：第一个可运行的本地检索模块

2026-09-22｜实现阶段：M1 的本地检索部分

这是可以直接运行的 Python 小项目。已包含22张知识卡、8个来源、中文命令行和10项软件测试。无第三方依赖、无联网、无模型密钥。

它能按关键词和同义词查资料，不能理解任意自然语言、生成完整建议或自主调用外部工具。后续再接大模型形成RAG，最后增加Agent循环。

## 在你的Mac上运行

1. 下载并解压 `LureSense_Starter_v01.zip`，会得到 `LureSense_Starter` 文件夹。
2. 打开终端。输入 `cd `（末尾留空格），把解压后的文件夹拖入终端，按回车。
3. 确认有Python 3.11或更高版本：

```bash
python3 --version
```

如果没有python3命令，或版本低于3.11，先配置独立Python环境；本项目不需要更改已有课程环境。终端中的python3和PyCharm解释器应指向你准备使用的环境。

4. 运行一次查询：

```bash
python3 app.py --query "水草附近可以先了解什么？" --limit 2
```

预期能看到K003和K010，包括资料主张、适用条件、项目推断和来源链接。它们是资料结果，不是现场有鱼的确认。

5. 进入连续提问模式：

```bash
python3 app.py
```

输入问题后按回车，输入 `exit` 退出。这个模式逐题检索，尚未保存对话上下文。

## 查看结构化结果

```bash
python3 app.py --query "水草" --json
```

输出JSON便于后续接大模型。结果中不输出鱼情概率；内部排序分值也不是置信度。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

本次运行10项通过。它们验证软件行为，不等同于前期准备包30个场景的模型评估，也不是实际钓鱼效果验证。

## 已知局限

检索依赖人工关键词，可能漏掉新说法；无法理解否定和复杂比较。范围检查也较保守，提到“海鲈”等词的比较问题会被拒绝。命中资料不代表资料回答了整个问题。学名按来源保留；佛州作钓方法仍保留地域和物种语境限制。
